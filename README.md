# Tucson-Police-Data-Analysis
Analysis of how call volume and event types change throughout time of day and over the course of a week. 

Dataset taken from https://gisdata.tucsonaz.gov/datasets/d0092810c2ea45ff938ae1c5b43c7b4a_0/explore (CSV not included in this repo due to its upload size)

As a part of this analysis, I created my first dashboard in Tableau to visualize some of the data and observations made. It is included here in a pdf format as "TPD_Dashboard".
